# CN 源码补丁

此目录是 Hermes 所有源码变更的登记表和理由说明，不是源码文件的第二份副本。

对于每个下游源码变更，记录：

- 稳定的 patch ID；
- 它实现的能力；
- 变更的上游文件和行为；
- 首个受影响的 Hermes commit；
- 聚焦的回归测试；
- 当前上游状态（`not-upstreamed`、`upstreamed` 或 `superseded`）。

如果某个补丁已经成为上游的 native 能力，更新能力状态，并在已经包含该能力的 commit 上停止应用
该补丁。在 Git 中保留补丁历史，同时让源码 commit 靠近负责该行为的模块。

目前还没有导入补丁。添加条目之前，先对照整理旧 CN-Core fork 记录；其中包含已经上游化、已经被
替代，或仅适用于另一种客户端传输方式的变更。
